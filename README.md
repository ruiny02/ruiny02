## About

I work across the whole robotics stack, from sensors and state estimation to the vehicle's actuators.

🤖 **Robotics & autonomous driving** — localization (LiDAR / IMU / GNSS / wheel fusion), planning, and control, in simulation (MORAI, CARLA, Gazebo) and on real vehicles.

🚗 **Project Leader (PL) of the autonomous team at HEVEN** (Dec 2025 – present; member since Dec 2024), SKKU's student vehicle club (~60 members). I'm also the main developer of its vehicle software.

🔩 **Mechanical background** — Inventor/Nastran structural design, dynamics, Arduino/ESP32 embedded control.

🧠 **AI on the edge** — TensorRT on Jetson and CUDA map search, plus VLM / RL research projects.

🛠️ **Tools for teams** — a shared repository template with an Issue → branch → draft-PR workflow on GitHub Projects, optional **StrictDoc** requirements traceability, Claude Code / Codex **skills**, **Notion MCP** hubs that agents read for context, CI with a prebuilt dependency image and ccache (builds ~51 → ~4 min), a two-pass AI PR review, and **Discord mentions** mapped from GitHub accounts. I also teach new members ROS2 and how to work with AI coding agents.
